# THAROS

Freelance marketplace inside Discord (2022). Clients post jobs, verified experts apply, and payment is held through PayPal until the client confirms the result. Includes expert verification, job chats, ratings, refunds and a support flow.

**Status:** discontinued, kept as an archive.

## Stack

Python, nextcord, PayPal REST SDK, OpenAI and DeepL for translations

## Run

```bash
pip install -r requirements.txt
cp .env.example .env   # add your own keys
python main.py
```
